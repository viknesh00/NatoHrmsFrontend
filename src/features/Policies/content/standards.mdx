# Standards & Integrations

This page lists relevant external references for security, privacy, responsible system design, and HR integrations. It describes reference material only. **The presence of this page or of application controls does not establish certification, audit success, standards conformity, or an SAP integration.** Confirm the organization's actual scope and evidence with its security, privacy, and integration owners.

## ISO/IEC 27001 — information security management

[ISO/IEC 27001:2022](https://www.iso.org/standard/27001) specifies requirements for an information security management system. ISO lists Amendment 1:2024 alongside the published 2022 edition. Use the standard as a reference for organization-wide risk management, controls, evidence, and continual improvement; do not treat application role checks alone as conformity evidence.

## ISO/IEC 27701 — privacy information management

[ISO/IEC 27701:2025](https://www.iso.org/standard/27701) sets requirements and guidance for establishing, maintaining, and improving a privacy information management system. The 2025 edition is the current published edition listed by ISO. The organization must determine its controller and processor responsibilities, privacy scope, and applicable requirements.

## IEEE 7000 — ethical system design

[IEEE 7000-2021](https://standards.ieee.org/ieee/7000/6781/) describes a process for addressing ethical concerns during system design, including eliciting stakeholder values and tracing them into system requirements and design decisions. It is a reference for product and governance review, not a certification claim for this application.

## SAP SuccessFactors

[SAP SuccessFactors API documentation](https://help.sap.com/docs/successfactors-platform/sap-successfactors-api-reference-guide-odata-v2) describes REST and OData API options for integrations. This front-end repository does not establish an SAP connector, tenant, credential, mapping, or production data flow. Any SAP integration must be separately designed and verified in the backend and deployment environment.

## Application controls to review

The application includes role-based navigation and protected routes, plus HR workflows for employee records, attendance, onboarding, leave, and work status. Security and privacy owners should validate the full deployment—including backend authorization, data storage, logging, retention, incident handling, and vendor configuration—against the organization's chosen scope.
